# Zaid & Muskaan – Our Love Story

## Run locally (VS Code)
Open the folder in VS Code → right-click `index.html` → **Open with Live Server**.
(Do not double-click the file – browsers block video/audio from `file://`.)

## Deploy on GitHub Pages
Push this whole folder to a repo → Settings → Pages → Deploy from branch → `main` / root.

## IMPORTANT – link preview (WhatsApp etc.)
In `index.html` (top, inside `<head>`) replace `YOUR-GITHUB-USERNAME` and `YOUR-REPO-NAME`
(5 places: og:url, og:image, og:image:secure_url, twitter:image) with your real address, e.g.
`https://zaid123.github.io/love-story/`. The preview image is `assets/og-preview.png`
(only used for the shared-link thumbnail, it is not shown inside the website).
WhatsApp caches previews – if you test an old link, add `?v=2` to the URL.
